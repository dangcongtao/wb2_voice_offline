- id: response id, MCU gửi làm value trong CMD_RESP_SET {"cmd":15,"data":[cmd_id, id]}.
  value 0 = ngẫu nhiên, 1 = câu mặc định của lệnh (với wake word là câu id 1).
- Giọng chọn bằng CMD_VOICE_SET {"cmd":17,"data":[1..4]}.
- Cùng một id, mỗi giọng nói một câu khác nhau (cùng ý), xem 4 bảng dưới.
- id 11..19, 70, 71 chip tự phát (học lệnh, khởi động, đi ngủ), không gắn với lệnh nào.
